# HopeHRS Project Glossary

| Term | Definition |
| :--- | :--- |
| **Soft Delete** | Marking a record as 'INACTIVE' in the database instead of permanently deleting the row. |
| **record_status** | The database column used to toggle visibility for the front-end. |
| **SuperAdmin** | The user role with full system access and override capabilities. |
| **Audit Trail** | A chronological record of changes made to any employee data. |
| **M5** | Milestone 5: The current phase focusing on Security and Documentation. |
